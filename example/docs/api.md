### `GET /orders` — Список заказов

*GET*

#### Query-параметры

| Поле | Тип | Описание |
| --- | --- | --- |
| `limit` *(необязательное)* | `Number` | Сколько заказов вернуть по умолчанию: `20` |
| `status` *(необязательное)* | `String` | Фильтр по статусу |

#### Успешный ответ

**200**

| Поле | Тип | Описание |
| --- | --- | --- |
| `orders` | `Object[]` | Список заказов |
| `orders.id` | `Number` | Идентификатор заказа |

**Успех**

```json
{ "orders": [ { "id": 10 } ] }
```

<a id="get-users-id"></a>

### `GET /users/:id` — Получить пользователя

*GET · доступ: user*

Возвращает профиль пользователя по идентификатору.

Поле `email` доступно только владельцу профиля.

#### Заголовки

| Поле | Тип | Описание |
| --- | --- | --- |
| `Authorization` *(обязательное)* | `String` | Bearer-токен |

#### Параметры пути

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` *(обязательное)* | `Number` | Идентификатор пользователя |

#### Примеры

**Пример запроса**

```curl
curl -H "Authorization: Bearer TOKEN" http://localhost:3000/users/1
```

#### Успешный ответ

**200**

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | `Number` | Идентификатор |
| `name` | `String` | Имя |
| `email` *(необязательное)* | `String` | Почта |

**Успех**

```json
{ "id": 1, "name": "Анна" }
```

#### Ошибки

**404**

| Поле | Тип | Описание |
| --- | --- | --- |
| `UserNotFound` |  | Пользователь с таким `id` не найден |

**Ответ 404**

```json
{ "error": "UserNotFound" }
```
